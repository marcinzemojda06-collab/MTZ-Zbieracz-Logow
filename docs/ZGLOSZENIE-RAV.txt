APPLICATION AND LAUNCHER BEHAVIOR
MTZ Zbieracz Logow is a Windows desktop tool for collecting and packaging
Minecraft logs and selected installation files. The launcher stages and
copies application files locally, creates a desktop shortcut through
WScript.Shell, and starts the PowerShell WinForms application.

Static review of both complete launchers found:
- Start-Process with WindowStyle Hidden;
- PowerShell arguments containing WindowStyle Hidden and ExecutionPolicy Bypass;
- a shortcut targeting PowerShell with those arguments;
- no file-download code, encoded command, Invoke-Expression, antivirus
  configuration change, or AMSI bypass in these launchers.

These observations do not certify the complete application or identify the
actual detection rule. The generic alert description mentions downloading
among possible behaviors; the evidence does not establish such activity.
Hash agreement identifies each sample and is not a security verdict.

RC2 adds required-file preflight checks and validates a staged application
before replacing the existing installation. Startup flags remain unchanged.
Its passing code tests do not constitute antivirus clearance. The new RC2
copy block remains unresolved. Historical test results are preserved.
