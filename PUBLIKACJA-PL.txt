OPIS DO STRONY WYDANIA
MTZ Zbieracz to lokalna aplikacja Windows do przygotowywania diagnostyki
Minecraft Java i pełnych kopii instancji. Po wybraniu profilu obserwuje
sesję gry i tworzy ZIP, który można dołączyć do zgłoszenia lub rozmowy.

Wersja 0.3.0 RC1 dodaje wybór profili, bezpieczne anulowanie, wspólny
instalator, blokadę równoczesnej aktualizacji, poprawki odtwarzania
oraz usprawnienia opcjonalnego rozszerzenia Opery/Chromium.
Szeroki pasek pokazuje postęp wykonanej pracy.

Pobierz plik Windows, wypakuj całość i uruchom Uruchom-MTZ-Logi.cmd.
Nie umieszczaj aplikacji w katalogu mods.
Program nie wymaga klucza API i sam nie wysyła wiadomości.
Domyślnie zbiera ograniczoną diagnostykę. Pełna kopia jest osobnym wyborem
i zawiera oryginalne, nieanonimizowane pliki instancji.

To kandydat do wydania. Testy kodu wykonano na Linuksie i jawnie opisano
ich ograniczenia. Końcowe sprawdzenie Windows PowerShell 5.1, WinForms,
skrótu i bieżącej Opery pozostaje wymagane. Wcześniejszy launcher był
zgłaszany przez antywirusa; nie potwierdzono rozwiązania tamtego zgłoszenia.
Nie wyłączaj ochrony w celu uruchamiania aplikacji.
