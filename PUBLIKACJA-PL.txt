OPIS WYDANIA
MTZ Zbieracz to aplikacja Windows do zbierania diagnostyki Minecraft Java
oraz pełnych kopii instancji. RC2 zawiera poprawkę instalatora: sprawdzenie
kompletu plików przed uruchomieniem PowerShella, kontrolę launchera oraz
kontrolę przygotowanego katalogu przed zastąpieniem poprzedniej aplikacji.

Paczka podmiany zawiera folder Aplikacja i osobną instrukcję PODMIANA-PL.txt.
Można skopiować zawartość Aplikacja do obecnego folderu programu albo
uruchomić dołączony instalator z osobno rozpakowanej paczki. Drugi wariant
zachowuje poprzedni katalog programu w Kopie-aplikacji. Ustawienia i ZIP-y
użytkownika są przechowywane obok folderu Aplikacja.

Szeroki pasek pokazuje procent wykonanej pracy. Nowa instalacja domyślnie
wybiera szybką diagnostykę. Pełna kopia jest osobną opcją i zawiera
oryginalne, nieanonimizowane pliki instancji. Program nie wymaga klucza API,
a wysłanie wiadomości lub załącznika pozostaje czynnością użytkownika.

Weryfikacja podmiany obejmuje automatyczne testy launchera i Windows
PowerShell 5.1, z jawnymi ograniczeniami opisanymi w WERYFIKACJA-PL.txt.
Interaktywny test GUI i akceptacja RAV pozostają niepotwierdzone.
Wykrycie wcześniejszego launchera przez RAV nie jest uznane za rozwiązane.

PLIKI
Główny plik: MTZ-Zbieracz-Logow-Podmiana-0.3.0-rc.2.zip
Kontrola integralności: SHA256SUMS.txt
Opcjonalna paczka źródeł powstaje tylko z --with-sources.

PRZYGOTOWANIE
1. Uruchom świeże testy dla bieżących źródeł i zapisz dowody RC2.
2. Sprawdź zakres i sumy plików w release-validation.json.
3. Zbuduj paczkę poleceniem python tools/build-release.py.
4. Zweryfikuj gotowy ZIP i zawartość release-manifest.json.
5. Jeżeli publikujesz przez GitHub Release, przygotuj wydanie pre-release
   dla właściwej rewizji i dołącz dokładnie sprawdzoną paczkę z jej sumą.
6. Udostępnij rzeczywisty adres opublikowanego wydania.

Źródła i dystrybucja programu nie zawierają zebranych logów Minecrafta,
światów, danych kont ani katalogu %LOCALAPPDATA%\MTZ-Logi użytkownika.
